# 🚀 resty-stealth-suite

`resty-stealth-suite` 是一个基于 **OpenResty (Nginx + Lua)** 打造的高性能、轻量级、零指纹隐形安全网关与代理隧道套件。本套件致力于在不引入外部数据库（如 Redis/MySQL）的前提下，实现绝对物理隐形、防 AI 行为学探测、反主动扫描和强门禁白名单机制。

本套件包含以下两个核心子项目：

---

## 🛡️ 1. [restyguard](./restyguard/) — 四层流量清洗与自适应 TOTP 动态安全网关
*   **定位**：部署在服务器入口的 443 单端口多路复用流网关。
*   **核心特性**：
    *   **SNI 预读动态路由**：无需提前在 Nginx 配置文件中硬编码，支持通过 YAML 或环境变量自适应动态路由分发（如 `*.domain.com` 模糊匹配分流）。
    *   **无状态多用户 TOTP 动态口令**：深度融合 Google Authenticator 等手机验证器，提供前后均分的 5 分钟极宽时间滑动缓冲区，极致提升时钟容差度。
    *   **零弹窗高保真伪装回落**：彻底摒弃存在 401 弹窗破绽的传统验证，口令缺失或错误时 100% 悄无声息地反代回落至高保真假首页（如 Bing、AList、私有云等），对主动特征扫描呈现 100% 的业务欺骗。
    *   **302 临时重定向清洗**：验证通过后 0.1 秒内秒速洗刷带参长链，保持浏览器历史栏绝对整洁，防止鉴权 Token 物理泄露。

👉 **[前往阅读 restyguard 详细文档与部署指南 ➔](./restyguard/)**

---

## 🚪 2. [restytunnel](./restytunnel/) — 极真 TLS 1.3 指纹隐形正向代理隧道
*   **定位**：支持双域名、多用户隔离的高抗封锁、低特征正向代理隧道。
*   **核心特性**：
    *   **公网 TLS 1.3 绝对加密**：正向代理握手全部包裹在 TLS 1.3 强加密隧道内，对外部审计呈现 100% 正态分布的标准高熵二进制密文流动，完美伪装融入公共网络背景噪声。
    *   **商业级 TLS 握手指纹避障**：拒绝使用非标的自建 Go/Rust 协议栈，直接原生承载于最成熟稳定的 Nginx 握手层，JA3/JA4 指纹特征与大厂 CDN/API 接口物理一致。
    *   **双向 mTLS 源站加固**：一键集成 Cloudflare Authenticated Origin Pulls (AOP)，强制校验 Cloudflare 专属客户端证书，物理断绝扫描器绕过 CDN 直连源站刺探的行为。
    *   **一键智能授权书签 (Bookmarklet)**：内置 PWA/Service Worker 物理注销和 HTML 落地自清洗机制，点击书签秒速免密/带参授权加白，彻底解决隐私模式跨站丢 Cookie 及 SW 幽灵套娃霸屏顽疾。

👉 **[前往阅读 restytunnel 详细文档与部署指南 ➔](./restytunnel/)**

## 🛠️ 开源与部署建议
本套件支持通过 Docker 及 Docker Compose 进行零侵入式极速一键部署，建议：
1.  根据各子目录下的 `.env.example` 分别配置好您自己的环境变量（各子目录的 `certs/` 和 `ssl/` 证书已通过全局 `.gitignore` 安全屏蔽）。
2.  详情请进入各子项目目录，参考其完备的 `README.md` 与 `docs/` 文档库。
